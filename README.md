# HSdeck Scholomance Academy 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## API 편집 지침 (2026-11-14)

- 공개 카드 API는 `cards.json`(카드 목록/ID), `data/<CARD_ID>.json`(최초 사용·한국 날짜별 카드 상태), `art/`, `golden/`, `frame/`(일반·황금 카드 원화, 애니메이션, 텍스처·프레임)만 필요합니다. 자산 연결의 원본은 보존합니다.
- `render.json`, `history.json` 및 `*-date.json` 집계 출력은 중복이므로 재배포·재커밋하지 않습니다. 신규 schema/호환 래퍼를 늘리지 않습니다.
- 기존 카드별 JSON이 날짜별 키가 아니라면 원본 필드·출처를 보존한 무손실 마이그레이션으로 바꾸어야 합니다. 첫 날짜는 한국 실제 대전 가능일(베타 북미 시간 환산, 모험 실제 지구 개방, 이벤트 실개시일, 토큰 생성 가능일)입니다.
- 과거 날짜 오기입은 새 기록 추가만 하지 말고 이전 키 자체를 삭제·통합합니다. 이후 날짜는 변경된 필드만 기록하며 표시용 개행은 `<br></br>`로 통일합니다. 황금·프레임 바이너리는 변형하지 않습니다.
- `tools/`, `release-policy.json`, `.github/` 등은 실제 사용 중인 생성·검증 코드이면 보존하고, 임시 산출물만 정리합니다.
